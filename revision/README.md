# Introduction rewrite (revision folder)

Everything in this folder belongs to the Introduction revision of
*Joint Code-Dimension and k-Galois-Hull Enumerators for Simple-Root
Constacyclic Codes over Square-Free Affine Algebras*.

| File | What it is |
|---|---|
| `FINAL_SUBMISSION.tex` | Convenience copy of the revised manuscript, for reading and diffing on GitHub. The **authoritative** copy is the one inside `Audit 3 JOINT_Paper_Source_and_Supplementary_Files.zip` at `JOINT_Paper_Package/manuscript/`; the two are byte-identical when this folder was written. |
| `NEW_INTRODUCTION.tex` | The rewritten Introduction alone, as it appears in the manuscript (the TikZ workflow figure that follows it in the manuscript is not repeated). |
| `INTRODUCTION_MAPPING.md` | The mapping used for the rewrite: old statement → supporting reference → role in the new text, plus what was rewritten and why. The same file is in the package under `author_notes/`. |
| `Introduction_revised.pdf` | **Reading PDF of the new Introduction** (4 pages): the text of Section 1, Fig. 1 and the list of the references it cites. Generated by `build_pdf.py`; a reading copy, not the journal build. |
| `NEW_INTRODUCTION_preview.html` | Reading preview of the same text in the browser (MathJax). Generated, not a source file. |
| `figure1_workflow.png` | Fig. 1, extracted from the existing PDF build for the preview (the figure itself is unchanged). |
| `build_preview.py` | Regenerates `NEW_INTRODUCTION_preview.html` from `NEW_INTRODUCTION.tex` and the `.bbl` inside the package zip. |
| `build_pdf.py` | Regenerates `Introduction_revised.pdf`. No LaTeX distribution was available when it was produced (CTAN and GitHub release downloads are blocked in the sandbox), so the PDF is typeset with ReportLab and Matplotlib (mathtext): text in Times, every formula rendered from the manuscript LaTeX into a high-resolution image placed on the text baseline. Use it to read the revision; use LaTeX for the submission build. |

## What changed, in one line

Section 1 was rewritten so that it reads as a research story — definition and
applications → chronological literature (cyclic/negacyclic → constacyclic →
Galois hulls → distribution studies → finite rings and affine algebras) → the gap
stated as three counting questions → the contribution of the paper → results →
organisation — while keeping every mathematical claim, citation and
cross-reference of the previous Introduction. Because the order of first citation
changed, the bibliography files `FINAL_SUBMISSION.bbl` (in the package) were
reordered so that the printed numbers `[1]`–`[32]` match the new order of
citation. No other section of the manuscript was modified.

**The PDF in the package is the earlier build** (it still shows the previous
Introduction); recompile `FINAL_SUBMISSION.tex` with `references.bib` and
`sn-mathphys-num-local.bst` to obtain a matching PDF.
